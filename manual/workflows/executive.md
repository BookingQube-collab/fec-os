# Executive — COO / CEO / CFO workflow

For **Regional Operations**, **COO**, **CEO**, and **CFO** roles with cross-estate visibility. Amounts are in **QAR**.

## Daily (15 minutes)

1. **CEO** dashboard — estate revenue, EBITDA, margin, urgent tickets, incidents (24h). Run **Generate daily brief** when preparing leadership comms.
2. **Command Center** — **Exceptions** tab first; drill into venue packs only where intervention is needed.
3. **Notifications** — approvals at CEO/Finance tier for procurement and escalated items.

## Weekly

| Area | Pages |
| --- | --- |
| Performance | **Sites**, **Revenue** (Branch P&L, Leakage), **KPIs** |
| Operations | **Reports** (Board Pack, Branch League), **Weekly Reports** executive dashboard |
| Maintenance | Maintenance **Executive Report**, open work-order age |
| Compliance | **E3 Tracker**, **Compliance Center**, global expiry banner |
| Procurement | **Procurement → Analytics**, vendor concentration, pipeline stages |
| People | Headcount and salary spend on **People → Dashboard** (HR can detail) |

## Decisions and risk

1. **Decisions** — formal records with votes and AI summary for major calls.
2. **Risk Register** and **Compliance Center → Obligations** for audit prep.
3. **Forecasts** — scenario commentary for board or mall landlord updates.

## Administration (restricted)

- **Settings** (`/admin`) — roles and location scope.
- **AI Integrations** — provider routing and usage (server-side keys).
- **Diagnostics** — health scan and crash hub when investigating outages.
- **Remove all payroll** — CEO/COO testing only; destructive confirmation phrase required.

Executives should rely on **RBAC**: UI modules match granted capabilities; venue-scoped roles never see other branches’ data.
