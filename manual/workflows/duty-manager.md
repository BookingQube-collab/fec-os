# Duty manager — daily workflow

Typical shift for a **Duty Manager** or venue supervisor. Adjust steps to your site assignment and role capabilities.

## Start of shift

1. Sign in to FEC-OS. Confirm the **venue** in the top bar matches your site (not *All locations* unless you are estate-wide).
2. Open **Daily Operations → Dashboard**. Resolve anything in **Needs action** (briefing missing, incidents, urgent maintenance, complaints).
3. Open **Command Center** (`/occ`) → **Venues** → your branch. Skim tickets, incidents, and work orders in the site pack.
4. If handover notes are due, open the venue pack and file **Handover** for the outgoing shift.

## During the shift

| Task | Where in FEC-OS |
| --- | --- |
| Staff on floor | Daily Ops → Dashboard; People → Time & Attendance (present / late) |
| Shift calendar | Daily Operations → Roster (operations calendar — not Import roster) |
| Guest incident | Daily Ops → Incidents, or **Protocols** in OCC for standard procedures |
| Maintenance issue | Daily Ops → Maintenance → **Log issue**, or Maintenance → Requests |
| Guest complaint | Daily Ops → Complaints, or Guest Experience → Customer |
| Checklists | Daily Ops → Checklists or Operations → Tasks (photo proof, offline OK) |
| Low stock | Daily Ops → Inventory; escalate via Inventory module if needed |

Use **Surge mode** when you need a tighter header during busy periods or exceptions.

## End of shift

1. Complete opening/closing or hourly **Tasks** checklists with photo proof where required.
2. File **Briefings** (Daily Ops) with attendance counts and handover items; use **AI Assist** only as a draft — review before submit.
3. Update open **Incidents** and **Complaints** status or assign the next handler.
4. Command Center → **Handover** for the incoming duty manager.

## Permissions to remember

- Venue roles see **assigned sites only**.
- Roster import on People uses **Safe Sync** for venue roles (no authoritative replace).
- You cannot approve your own attendance **Corrections**.
