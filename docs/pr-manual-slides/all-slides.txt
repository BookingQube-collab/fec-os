=== SLIDE 3 ===
ACCESS
Your role controls what you can see and do
E3 PR SYSTEM · PRACTICAL USER MANUAL
03
Operational roles
Requester / User — create and follow own PRs
Supervisor — first-stage review and feedback
Approver — review assigned approval stages
Admin — manage operations, vendors and records
Super Admin — universal review, policy and system settings
Vendor access
Vendors do not use the staff dashboard
They enter through a secure self-service link
The link is scoped to the requested onboarding or update
Staff review submitted changes before use
Never forward a vendor link to another entity
If a control is missing, confirm your role and department assignment before reporting a system fault.

Your approval stage requirements are satisfied

=== SLIDE 30 ===
SECURITY
Protect links, documents and banking data
E3 PR SYSTEM · PRACTICAL USER MANUAL
30
Always
Use your own authenticated account
Share vendor links only with the named recipient
Mask banking details in screenshots and messages
Check role, entity and PR number before acting
Use approved storage for exports and documents
Never
Post invitation links in group chats
Copy full IBAN or identity data into comments
Approve because a requester says it is urgent
Create duplicate vendors to bypass onboarding
Change compliance status merely to unblock a PR
If you suspect the wrong person received a link, revoke or regenerate it through the authorised workflow and record the incident.
